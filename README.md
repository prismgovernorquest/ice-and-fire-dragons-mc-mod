Fire and Ice dragons roam the world alongside cyclopes, sea serpents, sirens, and hippogryphs.

## Features

- Fire and Ice Dragons with taming and riding
- Sea Serpents in ocean biomes with unique loot
- Cyclops, Troll, and Siren hostile mobs
- Dragon egg hatching and dragon progression system
- Dragon-forged weapons and armor from dragon bones

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
